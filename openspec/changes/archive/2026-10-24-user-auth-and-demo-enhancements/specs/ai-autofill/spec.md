# Spec Delta

## Purpose

Provides AI-assisted listing generation using Gemini 2.5 Flash multimodal vision to parse item photos into titles, categories, conditions, and suggested pricing, gated behind an operational demo feature flag.

## ADDED Requirements

### Requirement: Multimodal Item Photo Auto-Fill
The system SHALL accept an uploaded item photo and return structured listing suggestions generated by Gemini 2.5 Flash when the AI auto-fill feature flag is enabled.

#### Scenario: Successful multimodal auto-fill when feature enabled
- **WHEN** an authenticated user uploads a photo and clicks "Auto-Fill with AI" while `giveaway.ai.autofill.enabled=true`
- **THEN** the system analyzes the image via Gemini vision and returns suggested title, category, condition, and price within 5 seconds

#### Scenario: Auto-fill rejected when feature disabled
- **WHEN** a client calls the auto-fill endpoint while `giveaway.ai.autofill.enabled=false`
- **THEN** the system returns HTTP 403 Forbidden with an error indicating AI auto-fill is currently disabled
